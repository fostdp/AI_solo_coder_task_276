# 晶体晶胞堆积模拟

一个交互式的晶体结构3D可视化学习工具。

## 功能特性

- **三种晶胞类型**：
  - 简单立方 (SC)
  - 体心立方 (BCC)
  - 面心立方 (FCC)

- **3D可视化**：
  - 球棍模型展示
  - 拖拽旋转视角
  - 滚轮缩放
  - 自动旋转动画

- **空间利用率动画**：
  - 动态展示原子堆积过程
  - 实时显示利用率数值

- **学习记录**：
  - 自动记录学习行为
  - 后端API持久化存储
  - 本地存储降级方案

## 运行方式

### 方式1：直接打开（不使用后端）

直接在浏览器中打开 `index.html` 文件即可使用，学习记录会保存在浏览器本地存储中。

### 方式2：使用后端服务器（推荐）

1. 确保已安装 Node.js
2. 在项目目录下运行：

```bash
node server.js
```

3. 在浏览器中访问：`http://localhost:3000`

## API接口

- `GET /api/records` - 获取所有学习记录
- `POST /api/records` - 添加新记录，参数：`{ "text": "记录内容" }`
- `DELETE /api/records` - 清空所有记录

## 晶胞参数

| 类型 | 晶胞内原子数 | 配位数 | 空间利用率 |
|------|-------------|--------|-----------|
| 简单立方 | 1 | 6 | 52.36% |
| 体心立方 | 2 | 8 | 68.02% |
| 面心立方 | 4 | 12 | 74.05% |

## 操作说明

- **鼠标拖拽**：旋转3D视角
- **滚轮**：缩放视图
- **点击晶胞类型按钮**：切换不同晶胞结构
- **播放按钮**：播放堆积动画
- **暂停/继续**：控制自动旋转
- **重置视角**：恢复默认视角
